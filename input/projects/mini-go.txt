# Project Specification

## Project Name

**MiniGo AI**
*5×5 Go AI Agent using Minimax Search and Heuristic Evaluation*

---

# Overview

MiniGo AI is a competitive artificial intelligence agent developed for a 5×5 implementation of the board game Go. The project was initially created as part of a semester-long Artificial Intelligence course and later expanded into a full-stack application with a browser-based graphical interface.

Unlike machine-learning approaches such as AlphaGo, this project focuses on symbolic artificial intelligence techniques. The AI relies on adversarial search using the Minimax algorithm combined with Alpha-Beta pruning and a collection of handcrafted heuristic evaluation functions inspired by traditional Go strategy.

The objective of the project was to explore decision-making algorithms, optimization techniques, and game-tree search while operating under strict runtime constraints.

---

# Motivation

Go is one of the most computationally difficult board games because of its enormous branching factor and state space.

A naïve Minimax implementation quickly becomes computationally infeasible.

This project investigates how intelligent heuristic design and search optimization can produce a competitive Go-playing agent despite severe computational limitations.

---

# Board Representation

The board is represented as a 5×5 matrix.

Each position stores one of three values:

* 0 = Empty
* 1 = Black
* 2 = White

The AI receives:

* Current board state
* Previous board state
* Current move number

The output is the coordinate of the optimal move.

# AI Search Algorithm

The AI uses Minimax Search.

Because Go is a two-player zero-sum game, Minimax recursively explores future board states to maximize the AI's evaluation score while assuming the opponent always selects the strongest possible response.

The search is optimized using Alpha-Beta pruning, which eliminates branches that cannot affect the final decision.

This dramatically reduces the number of evaluated positions and enabled increasing the effective search depth while remaining within the assignment's runtime limit.

---

# Search Depth

Early and midgame:

* Fixed search depth of 3

Endgame:

* Adaptive search depth
* Search depth increases as the number of remaining legal moves decreases

This strategy improves endgame accuracy without violating runtime constraints.

---

# Move Ordering

Legal moves are evaluated using a predefined priority ordering.

The search examines:

1. Center
2. Near-center
3. Edge
4. Corner

This increases Alpha-Beta pruning effectiveness because stronger candidate moves are explored first.

---

# Heuristic Evaluation

The strongest component of the AI is its handcrafted evaluation function.

Instead of evaluating only captures or stone count, the AI combines numerous strategic heuristics inspired by human Go play.

Implemented heuristics include:

## Positional Weighting

Encourages center control during the opening.

---

## Shape Analysis

Evaluates common Go formations.

Rewards:

* Stable formations
* Efficient extensions

Penalizes:

* Weak shapes
* Over-concentrated groups
* Vulnerable formations

---

## Liberty Analysis

Counts liberties available to friendly and opponent groups.

Positions with greater mobility receive higher evaluation scores.

---

## Eye Detection

Detects secure internal spaces.

Rewards formations that are difficult to capture.

---

## Edge Penalty

Discourages excessive edge play before center influence has been established.

---

## Center Control

Prioritizes occupying strategically valuable central intersections.

---

## Opening / Midgame / Endgame Evaluation

Different positional weight tables are used depending on the phase of the game.

Opening:

* Strong center preference

Midgame:

* Balanced territorial expansion

Endgame:

* Positional weights removed
* Evaluation focuses primarily on captures and final score
